# SONIKA website

Live: https://mehulsoni000123.github.io (Mehul Soni, @mehuledits.ai)

- `index.html`, `downloads.html`, `guide.html` + `assets/` = the site. Apps, donate and socials are in the CONFIG block at the top of `assets/site.js`.
- `days/NN/` = released day guides (day.json, Prompt.txt, skills). `days.json` is generated by `python3 scripts/build.py --index-only`.
- Upcoming guides live in the private repo `sonika-vault` with `schedule.json`. `.github/workflows/publish.yml` runs every 15 minutes and publishes a vault day once its posting time has passed (needs the `VAULT_TOKEN` secret and Pages source = GitHub Actions).
