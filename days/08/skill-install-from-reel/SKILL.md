# Install a tool from a reel

1. **Watch.** Extract frames every 1–2 seconds and read all the on-screen text: tool names, URLs, GitHub repos, commands. Transcribe the audio if there is any.
2. **Identify.** Name the tool. Find its **official** source: the vendor's site or the original GitHub repo. Never use links from comments or DMs.
3. **Check.** Is it free or paid, and what is the licence? Does it have a decent reputation (stars, maintainers, recent releases)? What permissions does it need? Flag anything that asks for passwords, keys or payment.
4. **Plan.** List the exact install steps for the user's OS, including dependencies (Python, Node, FFmpeg).
5. **Install.** Run the steps. Ask before admin rights, system changes or anything paid.
6. **Test.** Run a minimal example and show that it works.
7. **Report.** What was installed, where, how to open it, and how to uninstall it.
