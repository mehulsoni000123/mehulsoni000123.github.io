Downloads

Every app here is free, has no ads and needs no login. Click the download button and it starts straight away. The source code is on GitHub if you want to check it or build it yourself.

Installing

  1. Click the download button on the app you want.
  2. Open the downloaded .exe, or unzip the .zip and open the app inside (Converter and Task Manager need no installer). If Windows shows "Windows protected your PC", click More info → Run anyway. This appears because I haven't paid for a code-signing certificate.
  3. Pick an install folder and finish. The app opens from the Start menu.
